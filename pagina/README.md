# ConexiónLuz

Plataforma de bienestar integral con historias de transformación, sesiones con terapeutas y herramientas para el crecimiento personal.

## Tecnologías utilizadas

- **Frontend:** Vite + React + TypeScript + shadcn-ui + Tailwind CSS
- **Backend:** Django + PostgreSQL
- **Infraestructura:** Docker + Nginx

## Desarrollo local

Requisitos: Node.js & npm, Python 3.12+, Docker.

```sh
# Clonar el repositorio
git clone <URL_DEL_REPOSITORIO>
cd conexionluz

# Levantar todos los servicios con Docker
docker compose up -d
```

El frontend estará disponible en `http://localhost` y el backend en `http://localhost:8001`.
